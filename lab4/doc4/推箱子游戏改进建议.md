# 推箱子小游戏改进建议

## 1. 当前 MVP 概况

实验4当前版本已经满足实验手册的核心要求：提供4个可选择关卡，使用8×8二维数组保存地图，通过 Canvas 绘制地板、围墙、目标、箱子和角色；玩家可以使用四个方向键或在棋盘上滑动，完成移动、碰撞、推箱、胜利判断和重新开始。首页展示关卡预览，游戏页显示当前关卡、移动步数和本地最佳记录。

当前版本适合作为课程验收的 MVP，但在关卡内容、交互容错、成长反馈和视听表现方面仍有继续扩展的空间。

## 2. 优化目标

- 界面更美观：统一冰原主题，加强动效、声音和状态反馈。
- 内容更丰富：增加关卡、难度梯度、挑战模式和成就系统。
- 操作更友好：提供撤销、提示、手势和无障碍支持。
- 代码更易维护：拆分游戏引擎、渲染层和页面状态，便于测试与扩展。

## 3. 功能优化建议

### 3.1 第一优先级：提升基础可玩性

#### 撤销一步

每次有效移动前保存玩家坐标和箱子数组快照，增加“撤销”按钮。推箱子容易因一次误操作进入死局，撤销能够显著降低挫败感。

建议保存结构：

```javascript
{
  player: { row, col },
  boxes: [[0, 1, ...], ...],
  moves: 12
}
```

限制历史栈最多保存50步，避免长期游戏占用过多内存。

#### 死锁检测

当箱子被推到非目标墙角时，提示“箱子进入死角，可撤销或重新开始”。后续可以继续识别靠墙无目标区、两个箱子互相阻挡等复杂死锁。

#### 关卡解锁与进度

当前4关全部开放，后续可改为完成前一关后解锁下一关。首页增加总星数、通关进度和最佳步数，让玩家拥有明确目标。为了不阻塞课程演示，可保留“练习模式全部开放”。

### 3.2 第二优先级：丰富游戏内容

#### 扩展关卡库

将4关扩展到12至20关，并按“入门、进阶、困难”分组。关卡数据增加元信息：

```javascript
{
  id: 5,
  name: '极地回廊',
  difficulty: '进阶',
  parMoves: 32,
  map: [[...], ...]
}
```

`parMoves` 表示推荐步数，可用于三星评价：完成即一星，不超过推荐步数的120%为二星，不超过推荐步数为三星。

#### 每日挑战

每天根据日期选择一个固定关卡，记录当日最佳步数和连续挑战天数。纯前端版本可保存在本地；若以后接入云开发，可增加好友排行榜。

#### 成就系统

可设置“首次通关”“四关全通”“一步不撤销”“达到最优步数”等成就，在首页增加成就入口和徽章展示。

### 3.3 第三优先级：增强操作体验

#### 智能提示

初级版本只提示当前可移动方向；高级版本可以使用广度优先搜索计算下一步建议。提示需要限制次数，避免完全替代玩家思考。

#### 操作设置

- 支持方向键和滑动两种操作方式开关；
- 提供左手、右手方向键布局；
- 允许关闭震动和音效；
- 提供更大的按键与高对比度模式。

#### 触觉反馈

有效推箱时使用轻震动，撞墙时使用短促反馈，通关时使用成功反馈。需要允许用户在设置中关闭震动。

## 4. 视觉与声音优化建议

### 4.1 Canvas 动画

当前角色与箱子按格瞬移。可以在150至200毫秒内插值移动，使角色行走和箱子推动更自然；箱子到达目标时增加金色光圈、粒子或轻微缩放动画。

### 4.2 多套主题皮肤

在冰原主题之外增加“海大校园”“深海基地”“森林仓库”等皮肤。地图逻辑保持不变，只替换地板、墙体、目标和角色资源。主题可通过通关或成就解锁。

### 4.3 音效与背景音乐

增加移动、推动、撞墙、到达目标和通关音效，并提供背景音乐开关。音频应体积小、可循环，并在页面隐藏或退出时暂停，避免影响其他页面。

### 4.4 状态反馈

- 箱子位于目标上时增加明显描边或对勾；
- 无效方向键点击时短暂变红；
- 通关弹窗显示步数、最佳记录和星级；
- 首页关卡卡片显示锁定、已通关、最佳记录等状态。

## 5. 技术结构优化建议

### 5.1 拆分游戏引擎

将移动判断、箱子推动、胜利判断和死锁检测提取到 `utils/game-engine.js`，页面只负责接收输入和更新界面。纯函数更容易使用 Node.js 编写自动测试。

建议接口：

```javascript
createGame(levelData)
move(state, direction)
isWin(state)
isDeadlocked(state)
undo(state)
```

### 5.2 使用 Canvas 2D 新接口

后续可以从旧版 `wx.createCanvasContext()`迁移到 Canvas 2D 节点 API，统一处理像素比和图片预加载，使高分辨率设备上的图像更清晰，也便于实现逐帧动画。

### 5.3 数据校验工具

为关卡增加自动校验：必须为8×8、只有允许的数字、玩家数量等于1、箱子数与目标数相同。还可通过搜索算法离线验证关卡是否存在解，避免发布无法通关的地图。

### 5.4 本地数据版本

最佳成绩、设置和成就应使用统一缓存对象并加入版本号，后续字段变化时可以迁移旧数据，而不是直接丢弃玩家进度。

## 6. 推荐实施顺序

| 阶段 | 功能 | 价值 |
| --- | --- | --- |
| V1.1 | 撤销一步、死角提示、音效开关 | 直接改善操作容错 |
| V1.2 | 12关、星级评价、关卡解锁 | 丰富主要内容和成长反馈 |
| V1.3 | Canvas 动画、主题皮肤、成就 | 提升界面表现和持续游玩动力 |
| V2.0 | 每日挑战、云端排行榜、好友分享 | 增加长期运营与社交能力 |

## 7. 测试重点

- 玩家不能穿墙、进入地图外区域或拉动箱子；
- 箱子后方被墙或其他箱子占据时不能推动；
- 所有箱子到达目标后只触发一次通关；
- 重新开始能够完整恢复玩家、箱子、步数和完成状态；
- 撤销可以准确恢复推箱前状态；
- 关卡地图满足尺寸、角色数量、箱子数量和可解性要求；
- 不同屏幕宽度和高像素比设备上 Canvas 不变形；
- 页面切换、锁屏和返回前台后音效与状态正确恢复。
