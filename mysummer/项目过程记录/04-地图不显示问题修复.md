# 地图不显示问题修复

## 问题现象

地图页的标题、数据总览和地点列表可以显示，但地图组件没有正常出现，或地图区域无法正确创建。

## 根本原因

项目使用微信小程序的 Skyline 渲染引擎。Skyline 是微信提供的新渲染方式，它与普通 WebView 在滚动容器的写法上存在差异。

地图外层使用了 `scroll-view`，但缺少：

```xml
type="list"
```

Skyline 会对滚动区域中的节点进行按需渲染。缺少正确类型时，嵌套的原生 `map` 组件可能没有被创建。

原代码还有一个不稳定绑定：

```xml
include-points="{{polyline[0].points}}"
```

页面首次渲染时 `polyline` 是空数组，此时 `polyline[0]` 不存在。虽然数据会在 `onLoad` 后补上，但地图组件的第一次初始化已经拿到了不稳定的值。

## 修复内容

1. 为地图页的 `scroll-view` 恢复 `type="list"`；
2. 删除 Skyline 下不需要的 `enhanced` 属性；
3. 在页面初始数据中提供地图中心点、缩放级别和空的 `includePoints` 数组；
4. 路线数据生成后，同时更新 `includePoints` 和 `polyline`；
5. 地图直接绑定 `includePoints`，不再访问尚不存在的 `polyline[0]`；
6. 为 Marker 增加常显文字标签，避免没有自定义 PNG 图标时地点不可辨认；
7. 地图错误事件写入开发者工具控制台，方便继续排查网络或平台错误。

## 相关专业术语

### Skyline

微信小程序的一种渲染引擎。渲染引擎负责把 WXML 和 WXSS 转换成手机上看到的页面。Skyline 性能较好，但部分组件写法与传统 WebView 不同。

### 原生组件

`map` 不是普通文本或卡片，而是由微信客户端提供的原生地图能力。原生组件对容器尺寸、渲染时机和数据类型更敏感。

### includePoints

一个由经纬度组成的数组。地图根据这些点自动调整视野，尽量把整条路线都显示在屏幕内。

## 修复后检查

1. 重新编译小程序；
2. 地图页应显示地图底图；
3. 视野应覆盖青岛到漠河、海拉尔等主要地点；
4. 地图上应出现地点名称标签和红色路线；
5. 点击地点应打开摘要卡；
6. 如果仍失败，查看控制台中的“地图组件加载失败”日志，此时更可能是网络、开发者工具缓存或地图服务问题。
