# 《兴安岭穷游记》项目过程记录

这个目录用于记录项目从 PRD 到代码的实现过程，帮助你理解每次改动，而不是只得到一份无法解释的成品代码。

## 当前进度

截至 2026-08-30，已经完成 PRD v1.1 中的 P0 骨架：

- 四个底部导航页面：地图、行程、攻略、工具；
- 三个共享详情页面：地点详情、路段详情、攻略详情；
- 本地统一数据源；
- 路线地图、时间轴、主题攻略和预算计算器；
- 页面跳转、返回、内容缺失和地图失败的基础处理。

“骨架”表示功能链路已经成立，但真实旅行日期、票价、里程、照片和完整游记仍需根据你的原始资料逐项补齐。

## 重要原则

- PRD 是需求依据，代码是实现结果，两者名称应保持一致。
- 尚未核实的真实信息写作 `null`，页面展示“待补”，不使用虚假数字。
- `mysummerapp/data/trip-data.js` 是 P0 业务数据的唯一来源。
- 本项目当前不依赖微信云开发、登录、后端服务器或第三方 UI 框架。
