### ArkTS 注意点（这一轮踩到的坑）
- @Builder 内部不能访问 @State @Watch 装饰的方法以外的实例方法（除非非 mutating 普通方法）。我用了 @Builder renderKey 在内部调 this.flagColor/flagBg（私有方法），ArkTS 允许，因为它们访问 @Builder 范围外的实例数据 OK
- `flagColor/flagBg` 返回 union 类型 (string | Color / string | Resource)。Text.fontColor/Text.backgroundColor 都接受这些 union，所以 OK
- 模板字符串中 optional 字段 `${item.op ?? ''}` 要避免 undefined 插值，ArkTS 严格模式不允许
- @Builder 的参数 weight 是 number (1 或 2)，传 layoutWeight(2) 让 `0` 跨两格；传 1 普通
- 跨满行的 `=` 单独作为一行 Row，不传 layoutWeight 也是 100% 宽
- `if (CheckEmptyUtil.isEmpty(resource))` 在某些版本会被拒（Resource 不属于 `object | string`），删掉即可

- 注：`rowIndex` 在内层 keyGenerator 中可经外层 itemBuilder 闭包捕获，故只缺 `colIndex`；外层 keyGenerator 的 `rowIndex` 则必须自己声明。

### 科学计算器逻辑修复（第二轮，按测试表）
用户测试表：`sin(π/2)=1`、`cos(π)=-1`、`tan(π/4)=1`、`ln(e)=1`、`(-3)*(-4)=12`、`sqrt(-4)=NaN/报错`，前 5 条全错、sqrt(-4) 连 `-` 都点不了。

**根因**：
1. `pendingFunc`（函数前缀）只能吃一个纯数字参数，无法接受常量（π/e）或子表达式（π/2），且 `insertConstant`/`appendOperator` 里 `resolvePendingFunc()` 在无参数时直接 return，导致常量插不进去、`-` 键失效。
2. 一元负号 `-` 只在「tokens 空」时当负号，`(` 后按 `-` 被当二元运算符 → `(-3)` 解析成 `( - 3 )` 出错。
3. 无结果舍入，`tan(π/4)` 得到 `0.9999999999999983` 而非 `1`。

**修复（重构函数为一等 token + 扩展调度场算法）**：
- **CalculateUtil.ets**：
  - 新增 `static FUNCTIONS[]` 与 `isFunction()`；`isSymbol()` 改为显式 `boolean`（去掉裸 `return;` 返回 undefined）。
  - 新增 `static roundSignificant(value, digits)`：按有效数字舍入，消浮点噪声（tan(π/4)→1）。
  - `parseExpression(expressions, angleMode?)` 支持函数 token：函数名入 operator 栈、遇 `)` 时若 `(` 下方紧邻函数则弹出到输出队列；`dealQueue` 遇函数 token 弹一个操作数调 `applyFunction`。
  - `applyFunction(input, op, angleMode?)` 内部处理 Rad/Deg 转换（sin/cos/tan 及反三角），并在返回前 `roundSignificant(r, 12)`；`applyPow` 同样加舍入。
- **ScientificPage.ets**：
  - 删除 `pendingFunc` 字段、`resolvePendingFunc()`、`computeFunc()`（角度换算已并入 `applyFunction`）。
  - `applyFunc`：有数→立即算；无数→把 `realOp`+`(` 作为 token 推入（`)(` 前补 `×` 隐式乘）。
  - `insertConstant`：常量可直接作为函数参数；`)(π` 前补 `×`。
  - `appendOperator`：新增一元负号判定（`sym==='-'` 且 currentNum 空 且 前一 token 为空/`(`/运算符 → `currentNum='-'`）。
  - `pushLeftParen`/`pushRightParen`/`backspace`/`memoryOp`/`startPending`/`evaluate` 移除 pendingFunc 逻辑；`evaluate`/`updatePreview` 把 `angleMode` 传给 `parseExpression`。
  - `refresh` 用 `funcDisplayName` 渲染函数 token（`sin`→`sin`、`sqrt`→`√` 等）。
- 用 Node 仿写解析器跑通 6 条测试全部 PASS。

### 科学计算器「点右括号 ≠ 点等号」修复
- 现象：闭合右括号后 `refresh()`→`updatePreview()` 立即显示最终结果，使 `)` 与 `=` 视觉上等价。
- 修复：`ScientificPage.pushRightParen()` 在 `open > close` 真正 push `)` 并 `refresh()` 后，追加 `this.calValue = ''` 清空预览；只有 `=` 才求值。未真正闭合（open<=close）时走 `else { this.refresh(); }` 不额外清空。
