# cloudPhoto 图片分享社区

实验六的完整微信小程序代码，基于原生小程序与微信云开发实现。

## 已实现

- 首页：云数据库图片流、按日期倒序、分页加载、下拉刷新、空态与错误重试
- 上传页：用户资料授权、相册/相机选图、云存储上传、进度反馈、可选图片文案、个人历史图墙
- 个人主页：按 `_openid` 筛选作者作品、分页加载、作品详情跳转
- 图片详情：下载到相册、分享好友、分享到朋友圈、全屏预览
- 照片管理：作者可删除自己的照片，并同步清理云存储文件和数据库记录
- 会话管理：支持退出当前小程序会话、清理本地资料与互动状态，并可重新登录
- 云函数：`getOpenid` 获取当前调用者经微信验证的 OPENID
- 稳定性：防重复上传、错误友好提示、数据库写入失败时清理孤立云文件

## 云端准备

1. 在微信开发者工具中选择已创建的云开发环境。
2. 确认云数据库集合名为 `photos`。
3. 将集合权限设为「所有用户可读，仅创建者及管理员可写」。
4. 右键 `cloudfunctions/getOpenid`，选择「上传并部署：云端安装依赖」。

> `_openid` 由云开发自动注入，前端代码不会手动写入。

## photos 文档字段

教材要求字段：`photoUrl`、`avatarUrl`、`country`、`province`、`nickName`、`addDate`，以及系统字段 `_id`、`_openid`。

完善版额外使用：

- `createdAt`：云端时间，用于同一天照片的可靠排序。
- `caption`：用户为照片填写的可选短文案。

## 验收建议

依次测试：首页空态 → 点击上传并授权 → 选择图片 → 观察上传进度 → 数据库出现记录 → 返回首页刷新 → 作者主页 → 图片详情 → 全屏预览/分享/保存。

真机首次保存图片时需要相册权限；模拟器没有系统相册，保存失败属于正常现象。
